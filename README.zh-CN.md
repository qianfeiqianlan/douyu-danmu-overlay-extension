# 斗鱼弹幕覆盖层插件

这是一个最小化的 Chrome 插件示例，用于在斗鱼直播间页面的视频区域上方显示实时弹幕。

## 功能介绍

- 仅在 `https://www.douyu.com/*` 页面生效。
- 默认关闭，不会自动显示弹幕，也不会自动连接弹幕服务。
- 点击 Chrome 工具栏中的插件图标，可以通过弹窗开关启用或关闭弹幕覆盖层。
- 自动查找斗鱼页面中的直播画面容器，并在其上方挂载透明弹幕层。
- 连接斗鱼弹幕 WebSocket 服务，动态接收直播间弹幕。
- 弹幕从右向左滚动显示。
- 弹幕不显示用户名，只显示弹幕正文。
- 尽量使用弹幕消息中携带的颜色字段显示原始颜色。
- 如果暂时无法解析房间号或连接失败，会显示少量演示弹幕，方便确认覆盖层是否正常挂载。

## 安装方式

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本文件夹：

   ```text
   douyu-danmu-overlay-extension
   ```

5. 打开或刷新斗鱼直播间页面。
6. 点击 Chrome 工具栏中的插件图标，打开「Show danmu overlay」开关。

## 当前限制

- 插件当前依赖 `.stream__T55I3` 这个页面选择器定位直播区域。该类名可能是斗鱼前端构建生成的，斗鱼改版后可能需要调整。
- 房间号解析逻辑比较简单，纯数字直播间 URL 的兼容性最好。
- 本项目只是学习和实验性质的浏览器插件，不是斗鱼官方产品。
